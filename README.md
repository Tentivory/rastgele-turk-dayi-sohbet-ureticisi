# Rastgele Türk Dayı Sohbet Üreticisi

## Bu Ne Lan?

Bu repo, dünyanın en ciddi, en akademik, en bilimsel Türk dayı sohbeti üreticisidir. 
Gerçekten çalışır. Python çalıştırırsan dayı gibi konuşur. 
Hiçbir şey anlamazsan bile, en azından çay içersin.

## Özellikler

- **Tamamen çalışan kod**: Saçma değil, ciddi bir algoritma.
- **Rastgele dayı cümleleri**: Eskiden biz... tarzında.
- **Yavaş konuşma modu**: Dayılar gibi düşünür, sonra konuşur.
- **Gizli özellik**: %10 ihtimalle bir fısıltı duyarsın. Duymayabilirsin de.

## Kurulum ve Kullanım

```bash
git clone https://github.com/Tentivory/rastgele-turk-dayi-sohbet-ureticisi.git
cd rastgele-turk-dayi-sohbet-ureticisi
python dayi_sohbet.py
# veya
python dayi_sohbet.py 10  # 10 tane sohbet için
```

Çıktı örneği:
```
=== TÜRK DAYISI SOHBET MODU AKTİF ===
Dayı #1: Gençler, eskiden biz ekmek alırdık 50 kuruşa...
```
